# New User Setup

The full, step-by-step guide for setting up a private instance of this backend together with the
Android app (Upstox account creation, VPS + domain, `.env`/Caddy configuration, optional Firebase
project, and pairing the app) lives in the Android repo, not here:

```
PersonalScalper/NEW_USER_SETUP.md
```

It's kept in one place (rather than duplicated in both repos) so the two copies can't drift out of
sync. If you only have this repo checked out, get `NEW_USER_SETUP.md` from the `PersonalScalper`
repo alongside it before starting.
